SAPLING by Grounded.
For grades 6 to 8, their families, and their teachers.

Upload everything in this folder to a new GitHub repo for Sapling:
  index.html, guides.js, share-image.png, apple-touch-icon.png, CNAME

CNAME points the repo at sapling.growwithgrounded.com.
In GitHub, turn on Pages for the repo (main branch, root folder).
In Cloudflare, add a CNAME record named "sapling" pointing to your GitHub Pages address, the same way soultree and sprout are set up.

guides.js holds the 40 When Life Changes guides. Edit or add a guide there without touching index.html.

Students' trees stay in each browser. Grown-ups can use Save to a file on the Grown-ups tab to back them up.

Before launch: move the old K to 5 tool off this subdomain (it now lives at sprout.growwithgrounded.com), confirm the Minnesota **CRISIS (274747) number with DHS, and check the links in guides.js.
